# D2GitSync v1.0 - Release Notes

## Overview
D2GitSync is a professional-grade save file synchronization system for Diablo 2 Resurrected that automatically backs up and syncs your character saves using Git.

## Release Contents
- **D2GitSync.bat** - Main launcher and synchronization script
- **D2SaveWatcher.ps1** - PowerShell file monitoring service  
- **README.md** - Quick start guide and feature overview
- **SETUP_GUIDE.md** - Comprehensive setup instructions
- **RELEASE_NOTES.md** - This file

## Key Features
✅ **Real-time save backup** - Changes synced within seconds  
✅ **Multi-computer sync** - Play seamlessly across different PCs  
✅ **Mod support** - Preserves directory structure for modded saves  
✅ **Professional logging** - Detailed logs with automatic rotation  
✅ **Error resilient** - Graceful handling of network/file issues  
✅ **Zero maintenance** - Automatic operation once configured  

## What's New in v1.0
- Initial public release
- Complete anonymization and genericization
- Professional error handling and user feedback
- Comprehensive documentation for public use
- Smart file type detection and filtering
- Git user auto-configuration
- Multi-platform repository support

## System Requirements
- **Windows 10/11** with PowerShell 5.1+
- **Git for Windows** (free download)
- **Diablo 2 Resurrected** (any version)
- **Administrator privileges** for file monitoring

## Quick Installation
1. Extract D2GitSync to a permanent folder
2. Edit `D2GitSync.bat` to configure your paths
3. Run as administrator for first-time setup
4. (Optional) Set up remote repository for multi-PC sync
